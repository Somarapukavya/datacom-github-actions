# Datacom GitHub Actions Workflow

This repository contains a basic GitHub Actions workflow created as part of a Datacom virtual experience task.

## 🔧 What This Project Demonstrates

- GitHub Actions workflow configuration
- Running a workflow when code is pushed
- Using an Ubuntu runner
- Executing a simple shell command

## ⚙️ Workflow

The workflow is defined in:

`.github/workflows/main.yml`

It runs on every push and executes a simple build job that prints a message using the Ubuntu environment.

## 🛠️ Technologies

- GitHub Actions
- YAML
- Ubuntu
- GitHub

## 🎯 Purpose

This project demonstrates the basics of setting up and running a GitHub Actions workflow.
